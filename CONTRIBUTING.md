# Contributing

Thanks for contributing to Laravel IP Guard.

## Development setup

```bash
composer install
```

## Quality checks

```bash
composer test
composer analyse
composer format
```

## Workflow

1. Create a focused branch such as `feature/*`, `fix/*`, `refactor/*`, `docs/*`, or `chore/*`.
2. Use Conventional Commits.
3. Add or update tests for behavior changes.
4. Keep public API and configuration changes backwards-compatible where practical.
5. Update the README when installation, configuration, commands, middleware behavior, or supported versions change.
6. Open a focused pull request with validation notes.

Security issues should not be reported through public issues; follow `SECURITY.md` instead.
