# Security Policy

## Supported versions

Security fixes are expected to target the currently maintained package version and supported Laravel/PHP combinations.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities through a public GitHub issue.

Report security concerns privately to the maintainer and include:

- affected package version
- Laravel/PHP environment
- reproduction steps
- expected and actual behavior
- potential security impact

Do not include real credentials, production IP lists, or private infrastructure data in public reports.

If a secret is exposed during testing or development, rotate it immediately and assess whether repository history also requires remediation.
